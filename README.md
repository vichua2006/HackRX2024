### Overview
When essential medications are out of stock, pharmacists are forced to manually call nearby pharmacies—a slow and inefficient process that disrupts workflow and delays patient care. RxSync solves this by utilizing live inventory-tracking to forecast drug demand and automate pharmacy-to-pharmacy communication intelligently.

By analyzing real-time inventory levels and prescription patterns, RxSync helps pharmacies restock smarter on a weekly basis, reducing the chances of critical shortages. In cases of immediate need, RxSync takes it a step further—using AI-powered voice calling to contact nearby pharmacies and coordinate transfers, so pharmacists can focus on what matters most: patient care.

Prototyped as an add-on to Kroll, Canada’s leading pharmacy management system, RxSync optimizes operations, minimizes downtime, and brings modern automation to the heart of community healthcare.

### Tech Stack
The demo is built with:
- React + Vite
- Bootstrap for styling
- [Bland.ai](https://www.bland.ai/) to handle call-automation, and
- OpenAi APIs post-call report generation.
